# Haoxuan ZHANG · 张浩轩

Personal portfolio in Chinese, English, French and Japanese, with Chinese and French PDF résumés.

This repository contains ready-to-publish static files. The entry point is `index.html`; no dependencies or build step are required. Images, stylesheets, scripts and PDF downloads are local files in the repository root.

Publish using GitHub Pages from the `main` branch and the root folder `/`.
Use the free default GitHub Pages address. No custom domain, paid plan or subscription is needed.
